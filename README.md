# m2vp.org

[Vue] source files for <https://m2vp.org>

## Attribution / Dependencies

See [./package-lock.json] for the complete set of transitive dependencies.

- [@mdi/js]
- [qr]
- [Vue]
- [Vue Router]

## Installation

```bash
git clone https://github.com/M2VP/m2vp.org.git
cd m2vp.org
npm i
```

## Dev / Test

```bash
npm run dev
```

...then open the URL displayed in console in a web browser.

## Build

```bash
npm run build
```

...then deploy the contents of `./dist/` to your web server.
